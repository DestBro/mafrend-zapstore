# Mafrend Zapstore Repository

This repository hosts the Zapstore metadata and releases for [Mafrend](https://mafrend.com).

## Purpose

Since the main Mafrend repository is private, this public repository is used to:
1. Provide a public `zapstore.yaml` for relay whitelisting.
2. Host public releases (APKs) for Zapstore to consume.

## Publishing to Zapstore

To publish a new version:
1. Update `zapstore.yaml` in this repository.
2. Create a new GitHub release and upload the APK.
3. Use the `zsp` CLI to publish.
